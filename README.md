Ecommerce Product Assistant

An AI-powered ecommerce assistant built to help users discover, search, and interact with products using Large Language Models (LLMs), embeddings, and intelligent retrieval workflows.

Features
AI-powered product search and assistance
Multiple LLM integrations
Embedding-based retrieval
Product recommendation workflows
Modular and scalable backend
Centralized configuration management
Custom logging and exception handling
Docker support
Automated testing setup


Tech Stack
Python
FastAPI
Large Language Models (LLMs)
Retrieval-Augmented Generation (RAG)
Vector Databases
Embedding Models
OpenAI
Gemini
Claude
Groq
Hugging Face
REST APIs
Docker
